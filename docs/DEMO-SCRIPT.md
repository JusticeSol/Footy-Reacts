# Demo video — script

About 90 seconds, 16:9, voiceover with on-screen captions. The message is
**"every take on every match, and now you can back the ones you agree with"**,
with Monad as the reason it feels instant.

**Footage sources:**

- **site:** captured from the demo URL (fixture board, match page, claim page)
- **rec:** your screen recordings of the steps that need sign-in (tipping,
  receipt, claim, account)
- **gfx:** motion graphics made in HyperFrames

## Recordings needed

Shoot these on the demo URL, signed in, at 1920×1080 or similar. Short,
unhurried clips are easier to cut than one long take.

1. **Tip:** Support → $3 → (sign-in if it appears) → "Sent $3 to …" with the
   card total updating.
2. **Receipt:** click receipt; the explorer page loads and shows the
   transaction.
3. **Claim:** `/claim` → your handle → "$X waiting" → YouTube Studio with the
   code in the description → back → collect → "$X is yours". Before
   recording, ask Claude to send your channel another test tip, so there is
   something to collect.
4. **Account:** the Account page with balance and history.

Your existing X clip (a tip plus the receipt) may already cover 1 and 2.

## Voiceover

Total is about 190 words, roughly 85 seconds at a natural pace. HyperFrames
can generate it with text-to-speech, or you can record your own. A real voice
usually lands better with judges.
