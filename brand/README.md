# Brand

The Footy Reacts mark is a speech bubble holding a football: reacting to the
match. It uses the site's palette and display face.

| | |
| --- | --- |
| Red | `#d5202a` |
| Cream | `#f4f1ea` |
| Ink | `#16130f` |
| Display face | Anton (`src/app/fonts`) |
| Mono face | Space Mono |

| File | Use |
| --- | --- |
| `avatar-800.png` | YouTube / X profile picture. Red ground, sized to survive a circle crop |
| `banner-2560x1440.png` | YouTube channel banner. Everything sits inside the 1546×423 mobile safe area |
| `mark.svg` / `mark-onred.svg` | The mark alone, for light grounds / red grounds |
| `lockup.svg` / `lockup-onred.svg` | Mark plus wordmark |
| `avatar.svg`, `banner.svg` | Sources for the PNGs |

The SVGs embed Anton, so they render correctly anywhere. To re-export a PNG,
open the SVG in Chrome at its own size and screenshot it, or use any SVG
renderer.
